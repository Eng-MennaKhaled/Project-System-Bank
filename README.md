🏦 C++ Bank Management System
نظام بنك كونسول تفاعلي بلغة C++ لإدارة حسابات العملاء من إضافة وحذف وتعديل وإيداع وسحب.

🎯 فكرة المشروع
بدل ما أحل تمارين منفصلة، جمعت كل مفاهيم C++ الأساسية في مشروع واحد. البرنامج بيحفظ كل العملاء في ملف نصي، وبيسمحلك تدير البنك كله من القايمة الرئيسية، من غير قاعدة بيانات.

🎮 طريقة الاستخدام
اختار من القايمة الرئيسية:
[1] Show Client List - عرض كل العملاء
[2] Add New Client - إضافة عميل جديد
[3] Delete Client - حذف عميل
[4] Update Client Info - تعديل بيانات عميل
[5] Find Client - البحث عن عميل
[6] Transactions - قايمة المعاملات
[7] Exit

ومن قايمة المعاملات:
[1] Deposit - إيداع
[2] Withdraw - سحب
[3] Total Balances - إجمالي أرصدة كل العملاء
[4] Main Menue - الرجوع للقايمة الرئيسية

🛠️ المفاهيم اللي استخدمتها
المشروع ده طبق أكتر من 15 مفهوم من C++:

🔹 Struct & Enum:
لتنظيم بيانات العميل sClient ومستوى القوايم enMainMenueOptions

🔹 Functions:
تقسيم الكود لـ 30+ فانكشن لإعادة الاستخدام وتنظيم المشروع

🔹 Vector:
تخزين كل العملاء في vector<sClient> عشان نتعامل معاهم بسهولة

🔹 File Handling:
حفظ وقراءة البيانات من ملف Clients.txt بـ fstream

🔹 String Manipulation:
تقطيع السطر بـ SplitString() والفاصل #//#

🔹 Struct to Line / Line to Struct:
تحويل بيانات العميل لسطر في الملف والعكس عشان نعرف نحفظ ونقرأ

🔹 Loops & Conditions:
للبحث في العملاء والتحقق من رقم الحساب

🔹 Input Validation:
منع تكرار رقم الحساب ومنع السحب أكتر من الرصيد

🔹 Pass by Reference:
استخدام sClient& عشان نعدل على الأصل مش النسخة

🔹 Console UI:
مسح الشاشة system("cls") وتنسيق الجداول بـ setw() و left

🔹 Mark For Delete:
حذف العميل عن طريق وضع علامة بدل المسح المباشر من الملف

📂 ملفات المشروع
Bank.cpp : الكود الأساسي للبنك
Clients.txt : ملف حفظ بيانات العملاء، بيتعمل لوحده أول ما تشغلي البرنامج

▶️ طريقة التشغيل
افتح Bank.cpp على Visual Studio او Code::Blocks
Build ثم Run
ابدأ بإضافة عميل جديد وجرب الإيداع والسحب
